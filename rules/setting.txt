### 조건
C-001 [확정] 현재 사용 중인 Windows 데스크톱을 원격 제어한다.
C-002 [확정] Jump Desktop의 장애·불편을 보완하는 독립 접속 수단을 만든다.
C-003 [확정] 맥 / 아이패드 / 아이폰 / 안드로이드에서 웹 접속한다.
C-004 [확정] Chrome / Safari / Samsung Internet을 대상에 포함한다.
C-005 [확정] 유료 원격제어 솔루션은 사용하지 않는다.
C-006 [확정] 영상 중계에 따른 클라우드 트래픽과 과금 가능성을 고려한다.
C-007 [제안] 호스트 PC의 상주 프로그램 설치를 전제로 한다.
C-008 [제안] 1인 사용자, 호스트 1대, 동시에 조작하는 세션 1개로 시작한다.
C-009 [미정] VPN 앱의 최초 설치를 허용할지 결정한다.
C-010 [확정] 피파온라인은 감독모드 화면 확인과 연속경기를 진행하기 위한 수동 클릭 조작이 목표다. 실제 경기 플레이는 범위에서 제외한다.
C-011 [미정] 서버·도메인·전기·추가 장비까지 월 추가 비용 0원이 필수인지 정한다.

### 요구사항
R-001 [확정] 외부에서 웹페이지를 열어 현재 PC 작업 화면을 보고 조작한다.
R-002 [확정] 피파온라인이 실행 중일 때 화면 누락·검은 화면 문제를 검증하고 개선한다.
R-003 [확정] 한글·영어 입력과 한영 전환을 지원한다. 물리 키보드와 모바일 키보드를 각각 검증한다.
R-004 [확정] 마우스 휠 없이 터치로 터미널 스크롤백을 위아래로 탐색한다.
R-005 [제안] 두 손가락 스크롤, 전용 스크롤 영역, PageUp/PageDown 버튼을 제공한다.
R-006 [제안] 터치패드 방식과 직접 터치 방식을 선택한다. 클릭·우클릭·드래그를 지원한다.
R-007 [제안] Ctrl / Alt / Shift / Win / Esc / Tab / 방향키와 한영 버튼을 제공한다.
R-008 [제안] 한글 조합이 불안정한 앱에는 로컬 입력창에서 완성한 문자열을 전송한다.
R-009 [제안] 끊김·탭 전환 시 눌린 키를 해제하고 재접속 상태를 표시한다.
R-010 [제안] 직결/중계 여부, 비트레이트, 누적 전송량과 연결 실패 원인을 표시한다.
R-011 [제안] 업무 모드와 화면 움직임 우선 모드의 해상도·FPS·비트레이트를 분리한다.
R-012 [제안] Windows 재부팅 후 자동 시작과 잠금 화면·UAC 동작을 검증한다.
R-013 [제안] HTTPS, 인증, 기기/세션 철회, 접속 기록을 갖춘다. 외부 공개 전 다중 인증을 적용한다.
R-014 [제안] 클립보드는 사용자 동작으로만 전송하고 기본 자동 동기화는 끈다.
R-015 [제안] 호스트의 현재 콘솔 세션을 우선한다. 별도 RDP 세션으로 대체하지 않는다.
R-016 [제안] 화면 스트림이 실패했을 때 업무 복구용 별도 웹 터미널을 후속 검토한다.

### 룰
G-001 [확정] 조건·요구사항·룰과 변경 이력을 파일로 기록하고 버전 관리한다.
G-002 [확정] Jump Desktop 외 무료·오픈소스 솔루션도 벤치마킹한다.
G-003 [제안] 검증되지 않은 브라우저 호환성·게임 지원·접속 성공률을 보장하지 않는다.
G-004 [제안] 검증된 캡처·인코딩 엔진을 우선 재사용하고 필요한 입력 UX를 개선한다.
G-005 [제안] 영상 게이트웨이는 PC 또는 같은 LAN에 둔다. 클라우드 영상 경유는 기본값으로 삼지 않는다.
G-006 [제안] 유료 중계는 기본 비활성화한다. 중계 예산과 상한이 정해지기 전 자동 유료 전환을 하지 않는다.
G-007 [제안] 비밀번호·토큰·개인키·페어링 정보·원본 화면·입력 내용은 Git에 넣지 않는다.
G-008 [제안] 게임 보안 기능을 우회하지 않는다. 호환되지 않으면 제한과 대안을 기록한다.
G-009 [제안] 기존 Jump Desktop 설정을 유지하며 병행 검증한다.
G-010 [제안] 실제 채택 버전·커밋·라이선스와 테스트한 OS/브라우저 버전을 기록한다.
G-011 [확정] GitHub 공개 저장소에서 관리하고 지인과 공유·공동 개선한다.
G-012 [제안] 외부 기여는 이슈와 Pull Request로 받고, 개인 환경과 접속 정보는 local/에만 기록한다.
