# 검증과 버그 기록

모든 테스트는 현재 미실행이다. 아래 수치는 제품 성능 주장이 아닌 초기 합격 목표다.

## 환경 기록

- 확인일: 2026-10-15
- 호스트 OS / GPU / 드라이버: 개인별 local/environment.md에 기록 (공개 저장소 제외)
- 소프트웨어 버전/커밋/라이선스: 미선정
- 공유기/CGNAT/업로드 속도: 미확인
- 클라이언트 OS/브라우저/키보드: 기기별 기록 필요

## 기기 행렬

| 기기 | 브라우저 | 입력 | 상태 |
|---|---|---|---|
| Mac | Safari, Chrome | 물리 키보드, 트랙패드 | 미실행 |
| iPad | Safari, Chrome | 화면 키보드, 외장 키보드, 터치 | 미실행 |
| iPhone | Safari, Chrome | 화면 키보드, 터치 | 미실행 |
| Android | Chrome, Samsung Internet | 화면 키보드, 터치, 외장 키보드 선택 | 미실행 |

같은 브라우저 이름이어도 OS별 구현과 기능이 같다고 가정하지 않는다.

## 필수 시나리오

| ID | 관련 요구 | 절차 | 초기 합격 기준 |
|---|---|---|---|
| T-001 | R-001,015 | 로컬 메모장에 식별 문구를 열고 원격에서 수정 | 같은 콘솔의 문구가 양쪽에 반영 |
| T-002 | R-002 | 피파온라인의 창/테두리 없는 창/전체 화면에서 감독모드 진입·연속경기 시작 버튼을 수동 클릭하고 각각 10분 관찰 | 화면 갱신·버튼 식별·클릭 성공. 실제 경기 플레이는 제외 |
| T-003 | R-003,008 | 메모장·Windows Terminal·실사용 편집기에 '한글 abc 123 테스트' 입력, 수정·백스페이스, 한영 20회 전환 | 누락·중복·깨짐 없음. 물리/모바일 경로 별도 기록 |
| T-004 | R-004,005 | 터미널에 500줄 출력 후 터치로 위아래 탐색 | 명령 히스토리 대신 스크롤백이 이동, 웹페이지가 끌려가지 않음 |
| T-005 | R-006,007 | 우클릭·드래그·Ctrl+C·Esc·Tab·방향키·화면 한영 버튼 | 기대한 원격 동작, 키 고착 없음 |
| T-006 | R-009 | modifier 누른 상태에서 연결 끊기, 탭 이동, 화면 잠금 후 복귀 | 키 해제, 실패 원인 표시, 네트워크 복구 후 15초 이내 재접속 목표 |
| T-007 | R-010 | LAN/모바일 데이터/외부 Wi-Fi 각 10회 접속 | 허용 경로별 성공률 기록. 선정한 지원망에서는 10/10, 경로와 누적량 확인 |
| T-008 | R-012 | 재부팅, 로그아웃, 잠금, UAC 각각 시험 | 지원/미지원 명확히 기록, 권한을 낮추거나 UAC를 끄지 않음 |
| T-009 | R-011 | 720p·1080p, 30·60 FPS 후보로 30분 사용 | 평균/p95 지연·프레임 드롭·CPU/GPU·비트레이트 기록 |
| T-010 | R-001,012 | 모니터 꺼짐, 해상도 변경, HDR, 다중 화면 전환 | 화면·좌표 정상 또는 명확한 제한/복구법 |
| T-011 | R-013,014 | 미인증 접속, 로그아웃, 세션 철회, 클립보드 전송 | 미인증 제어 차단, 철회 반영, 임의 클립보드 전송 없음 |
| T-012 | R-010 | 중계 한도 도달과 중계 불가를 모의 검증 | 한도 초과 경로 차단, 이유 표시, 자동 유료 전환 없음 |
| T-013 | R-006 | 모바일 회전·확대·키보드 열기 후 클릭 | 대상 위치와 클릭 좌표 일치 |
| T-014 | C-002 | Jump Desktop을 사용하지 않고 접속 | 해당 서비스의 로그인/연결에 의존하지 않고 작업 가능 |

업무 모드 임시 목표: LAN 1080p/30 FPS에서 입력→화면 반영 p95 150ms 이하. 실제 종단 지연은 입력과 화면을 함께 촬영하는 방식 등으로 측정하고 WebRTC RTT를 종단 지연으로 대체하지 않는다. 외부망은 회선 RTT와 함께 별도 목표를 정한다. 감독모드는 버튼 식별·수동 클릭·진행 상태 확인을 우선하며 경기 플레이 성능은 요구하지 않는다.
