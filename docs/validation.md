브라우저 단독 검사의 이미지와 계정은 합성 fixture다. 실제 Windows 캡처는 파일에 저장하지 않았다. `local/previews/`에는 로그인/대시보드/모바일 UI만 있으며 공개 Git에서 제외한다. 실제 마우스/키 이벤트의 Windows 테스트 창 결과는 아래 VM 기록과 구분한다. 일반 사용자 앱의 입력 호환성, 모바일 실기기, 게임, 관리자 앱은 아직 미검증이다.

### 구현 중 발견하고 수정한 문제

- 서버 종료 뒤 지연된 WS close 콜백이 닫힌 SQLite에 접근함 → Hub 종료 상태 검사로 차단, 통합 재검증 통과.
- 계정 CLI도 Store 생성 시 활성 원격 세션을 초기화함 → 재시작 정리를 서버 시작 경로로 이동하고 회귀 검사 추가.
- session stop 시 capture token으로 진행 중 WS send를 취소하면 agent 소켓까지 중단될 수 있음 → 연결 생명주기와 제한된 전송 timeout 사용, 실제 두 번째 연결 검사 통과.
- 런타임 라이선스는 NuGet 일반 libraries가 아닌 framework downloadDependencies에 기록됨 → 실제 고정 runtime pack 버전을 추적하여 고지 포함, 누락 시 패키지 생성 차단.

후속 검사에서 Ctrl을 누른 채 두 번 클릭하면 전체 `release`가 두 번 전송되는 문제가 재현됐다. 정상 pointer-up과 예기치 않은 capture 상실을 구분하여 수정했다. 수정 전 신규 브라우저 검사는 예상 0/실제 2로 실패했고, 수정 후 Ctrl 유지와 blur/예기치 않은 capture 상실 해제 검사가 통과했다.

초기 CI의 `--skip-capture` 구성은 D-013에 따라 실제 캡처/VM 웹 제어 검사로 대체했다. 그래픽 세션이 없으면 실패 처리한다. 2026-10-15 쓰기 권한이 부여되어 `fce4226`까지 main 푸시를 완료했다. [첫 CI 실행](https://github.com/BigDude129/web-remote-desktop/actions/runs/38677256982)에서 Ubuntu 서버 18개/브라우저 4개가 통과했다. Windows VM에서는 배포 ZIP 다운로드·실제 GUI 로그인·화면·클릭·영문/한글·휠/드래그·Ctrl 유지/blur·재연결까지 통과했으나 마지막 GUI 로그아웃 호출에서 테스트 도구의 `InvalidOperationException`이 발생해 전체 검사를 실패 처리했다. 최소화 전의 소유 창 handle을 유지하고 로그아웃 전에 창을 복원하도록 도구를 보완했다. 재검증과 게시 결과는 [VM 검증 절차](vm-validation.md)에 이어 기록한다. 실패한 검사를 성공으로 바꾸거나 릴리즈 조건을 완화하지 않는다.

수정 커밋 `7bb10c2`를 main에 푸시한 뒤 [실행 38677845353](https://github.com/BigDude129/web-remote-desktop/actions/runs/38677845353)에서 서버 18개, 브라우저 4개, 실제 Windows VM 11개 검사가 모두 통과했다. GUI 로그아웃 후 웹 종료 표시, 온라인/활성 세션 0, Windows Ctrl/마우스 버튼 해제까지 확인했다. 이 결과는 테스트 창의 입력 검증이며 Windows 11의 일반 앱/모바일/외부망 검증을 대신하지 않는다.

설치 창은 합성 릴리즈 정보와 긴 SHA-256을 펼친 상태, 기기 목록은 온라인/오프라인 및 긴 한·영 기기명으로 확인했다. 작은 화면의 설치 안내는 창 내부 세로 스크롤로 끝까지 읽을 수 있다. 처음 확인한 확대 화면에서 통계 보조 설명이 카드 폭을 넘는 것을 발견해 한 줄 고정을 제거한 뒤 다시 확인했다. 일회성 점검 스크립트와 합성 화면 캡처/결과는 Git 제외 `local/review-typography.ts`, `local/previews/typography/`에만 둔다.

재현 시 `npm run check`, `npm run test:browser` 후 브라우저 개발자 도구에서 위 폭을 순회한다. 확대 확인은 `document.documentElement.style.fontSize = '32px'` 또는 `'20px'`를 적용하고 기본 확인 전 제거한다. 설치 창의 다운로드 버튼·해시·서버 주소, 긴 기기명, 뷰어의 종료/문자열 입력/특수 키가 가로로 잘리지 않는지 확인한다. 원격 화면은 합성 데이터만 사용했으며 이 CSS 검증을 신규 Windows 실기기·외부망·모바일 실기기 검증으로 취급하지 않는다.
