# 0.1.1 — 입력 실패 시 화면 유지

Windows가 마우스/키 입력을 거부했을 때 원격 세션 전체가 종료되던 문제를 수정한다. 화면은 계속 전송하고 입력은 일시 중지한다. 웹에서 경고를 확인하고 '입력 다시 시도'로 재개할 수 있다.

서버/웹을 먼저 갱신하고 에이전트를 교체한다. 입력 복구는 start/ready에서 협상하며 구버전 서버/agent 조합은 기존 동작을 유지한다. 잠금/UAC·캡처 실패는 여전히 종료되며 게임 호환성을 보장하는 수정은 아니다.

검증 상태는 docs/validation.md 참고. 현재 파일럿 빌드이며 공개 Release 게시 완료를 뜻하지 않는다.

웹 후속 패치: iPad Caps Lock을 한/영으로 변환하는 옵션(기본 켜짐)을 추가했다. 웹만 갱신하며 agent 바이너리 변경은 없다. iPadOS 하드웨어 키보드의 Caps Lock 언어 전환이 켜져 있으면 웹이 키를 받지 못할 수 있어 설정 안내와 화면 한/영 버튼을 제공한다. 실기기 해결 여부는 재시험 필요.
