# DeskLink v0.1.0

웹 로그인과 Windows 에이전트를 연결하는 첫 MVP입니다.

- 내 계정의 기기 목록, 온라인 상태, 검색, 연결 기록
- Windows GUI 로그인/원격 허용/중단, 브라우저에서 실제 현재 화면 제어
- 기본 모니터 JPEG 최대 1600×900/목표 5 FPS, 마우스/키보드/한글 완성 문자열
- 사용자 소유권, CSRF/Origin, 세션 만료/철회, 단일 제어자, heartbeat
- MIT 라이선스, 원문 의존성 고지, 버전/최신 릴리즈 안내
- Ctrl+클릭에서 modifier 유지, 포커스/비정상 포인터 상실 시 입력 해제
- Windows VM의 배포 ZIP 설치·실제 웹 제어 검사를 릴리즈 게시 조건에 포함

Windows x64에서는 ZIP을 풀고 DeskLink.Agent.exe를 실행하세요. 서버 주소와 웹과 같은 계정으로 로그인합니다. 운영자는 저장소 README의 서버 실행 방법을 참고하세요. 기본 계정은 없으며 서버 로컬에서 `npm run user:add`로 생성합니다.

이 릴리즈는 Microsoft RDP 호환 구현이 아닙니다. 영상은 서버 WebSocket을 경유하며 오디오, 파일 전송, 다중 모니터, 잠금/UAC/로그온 전 화면, 무인 서비스, P2P, 고성능 게임 스트리밍은 지원하지 않습니다. 실제 모바일 기기·게임·대상 앱의 한영 입력 검증은 남아 있습니다. 현재 바이너리는 코드 서명 전 개발 배포입니다.

ZIP의 SHA-256을 함께 제공한 SHA256SUMS.txt와 비교할 수 있습니다. LICENSE.txt 및 THIRD-PARTY-NOTICES.txt를 함께 보관하세요. 업데이트는 기존 에이전트를 종료하고 새 ZIP을 풀어 실행합니다. 자동 파일 교체나 조용한 설치는 하지 않습니다.
